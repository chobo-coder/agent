# Save Context

현재 세션의 작업 컨텍스트를 memory 파일에 저장하여, 다른 세션에서도 동일한 맥락으로 작업을 이어갈 수 있게 한다.

## 트리거 조건

- 사용자가 "다음에 이어서 하자", "이어서 하자", "컨텍스트 저장", "save context", "진행 상황 저장" 등을 요청할 때
- `/save-context` 명령어로 직접 호출할 때

## 실행 절차

### 1단계: 현재 상태 수집

다음 항목을 파악한다:

- **마지막 작업**: 이번 세션에서 수행한 주요 작업 요약
- **진행 상태**: 각 워크플로우/모듈의 구현 완료 여부
- **다음 할 일**: 다음 세션에서 이어서 해야 할 작업
- **변경된 파일**: 이번 세션에서 수정/생성한 파일 목록
- **미결 사항**: 열린 질문, 보류된 결정, 사용자 확인 필요 사항

### 2단계: MEMORY.md 업데이트

`/Users/hyeonjaeyeol/.claude/projects/-Users-hyeonjaeyeol-Desktop-WorkPlace-agent/memory/MEMORY.md` 파일을 업데이트한다.

구조:

```markdown
# Agent Project Context

## 프로젝트 개요
(프로젝트가 무엇인지 한 줄 요약)

## 현재 진행 상태
(각 워크플로우/모듈별 완료 상태)

## 마지막 세션 요약
- 날짜: YYYY-MM-DD
- 수행 작업: ...
- 변경 파일: ...

## 다음 할 일
(우선순위 순서대로 나열)

## 미결 사항
(열린 질문, 보류된 결정)

## 주요 파일 맵
(핵심 파일 경로와 역할)
```

### 3단계: 상세 컨텍스트 파일 관리

MEMORY.md가 200줄을 넘지 않도록, 상세 내용은 별도 파일로 분리한다:

- `progress.md` — 워크플로우별 상세 구현 상태
- `decisions.md` — 확정된 설계 결정과 근거
- `next-steps.md` — 다음 작업의 상세 계획

### 4단계: 저장 완료 알림

저장이 완료되면 사용자에게 다음을 알린다:
- 저장된 항목 요약
- 다음 세션에서 "이전 컨텍스트 확인해줘" 또는 대화를 시작하면 자동으로 MEMORY.md를 참조한다는 안내

## 규칙

- MEMORY.md는 200줄 이내로 유지한다
- 세션별 임시 정보(현재 디버깅 중인 에러 등)는 저장하지 않는다
- 이미 CLAUDE.md에 있는 규칙은 중복 저장하지 않는다
- 기존 메모리 내용과 충돌하면 최신 정보로 덮어쓴다
