## 상태 전이 요약

```
IDLE
 └→ COLLECTING_PARAMS ←──┐
     └→ VALIDATING_PARAMS ─┤ (누락 시 루프)
         └→ QUERYING_DATA
             └→ SHOWING_QUERY_RESULTS ─── [사용자 판단 1]
                 ├→ LOADING_PARQUET → SHOWING_DATA_OVERVIEW
                 └→ SHOWING_DATA_OVERVIEW ─── [사용자 판단 2]
                     └→ PREPROCESSING
                         └→ ANALYZING_FEATURES
                             └→ SHOWING_FEATURES ─── [사용자 판단 3]
                                 └→ PREDICTING
                                     └→ SHOWING_PREDICTIONS
                                         └→ COMPLETED → IDLE
```

## LLM 사용 지점 (3+1)

```
┌───────────────────┬────────────────────────┬───────────────────────────────┐
│ 지점              │ LLM 역할               │ 입출력                         │
├───────────────────┼────────────────────────┼───────────────────────────────┤
│ COLLECTING_PARAMS │ Parameter Extractor    │ 자연어 → {product, dates,     │
│                   │                        │          process}             │
├───────────────────┼────────────────────────┼───────────────────────────────┤
│ SHOWING_QUERY     │ Intent Classifier      │ "로딩해줘" → {load: true}     │
│ _RESULTS          │                        │                               │
├───────────────────┼────────────────────────┼───────────────────────────────┤
│ SHOWING_DATA      │ Parameter Extractor    │ "결측치 평균" → {items: [...], │
│ _OVERVIEW         │                        │  params: {...}}               │
├───────────────────┼────────────────────────┼───────────────────────────────┤
│ SHOWING_FEATURES  │ Parameter Extractor    │ "col_3, col_4로 0.7"         │
│                   │                        │ → {features, threshold}       │
└───────────────────┴────────────────────────┴───────────────────────────────┘
```

## 채팅 시나리오 예시

```
Bot: 안녕하세요! 분석을 시작하려면 아래 정보를 입력해주세요:
     - 제품명, 시작일, 종료일, 공정

You: 제품A 1월부터 3월까지 공정_B
         │
         ▼ LLM: {product: "제품A", date_from: "2025-01-01",
         │        date_to: "2025-03-31", process: "공정_B"}
         ▼ 필수값 OK → 쿼리 실행

Bot: ✓ 조회 완료 (100건) + 오버뷰
     추가 데이터를 S3에서 로딩할까요?

You: 충분해
         │
         ▼ LLM: {load_additional: false}

Bot: 어떤 전처리를 적용할까요?

You: 이상치 제거하고 스케일링
         │
         ▼ LLM: {items: ["outliers", "scaling"], params: {method: "iqr"}}

Bot: ✓ 전처리 완료 + 피처 분석 결과
     예측에 사용할 피처와 임계값을 지정해주세요.

You: col_3이랑 col_s3_a로 70 기준
         │
         ▼ LLM: {features: ["col_3", "col_s3_a"], threshold: 0.7}

Bot: ✓ 예측 완료
     - 임계값 이상: 47건 / 미만: 53건
     분석 완료!
```
